# React + Vite
I built this tip calculator using React to practice core concepts and solve a real problem—I hate doing mental math when the bill comes.
What it does:

Takes your bill amount, tip percentage, and number of people
Calculates the tip amount automatically
Splits the total evenly between everyone
Updates results in real-time as you type

Technologies and concepts I used:

React with useState hooks for state management
Controlled components with onChange handlers to capture user input
Event handlers (onClick) to trigger calculations
Flexbox for responsive layout design
Clean CSS styling for a professional look

It's a straightforward project, but it covers essential React skills like component structure, state updates, and user interaction. Plus, it's actually useful when I'm out with friends and need to split the bill quickly."
